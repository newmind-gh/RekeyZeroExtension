# Support

## Community support

Use the GitHub issue templates for reproducible bugs and feature requests. Search existing issues first and provide the extension version, browser version, operating system, expected behavior, actual behavior, and synthetic reproduction steps.

Do not post API keys, credentials, real customer information, browser profiles, or raw logs containing sensitive data.

## Private contact

For security vulnerabilities, privacy concerns, or reports that cannot safely be made public, email **rekeyzero@outlook.com**. Security reports are handled according to [SECURITY.md](SECURITY.md).

## Supported scope

Community support covers:

- the latest RekeyZero Personal extension release;
- the current `main` branch on a best-effort basis;
- documented Chromium versions;
- the bundled synthetic extension test pages; and
- reproducible build and packaging problems.

Third-party portals, provider accounts, billing, browser policies, and unsupported browser versions require support from their respective operators.

Support is provided on a best-effort basis and does not create a service-level agreement.
